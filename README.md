# 💫 About Me:
About Me<br>I am an Information Technology undergraduate working at the intersection of full-stack engineering, academic mentorship, and community-driven digital initiatives. Rather than treating technology as isolated lines of code, I approach software as a holistic lifecycle—connecting hardware constraints, operating system scheduling, database reliability, modern web architectures, and real-world human needs.<br><br>My technical foundation centers on building accessible, high-performance web applications using React and Next.js, styled with Tailwind CSS and Bootstrap. On the back end, I design modular RESTful APIs and asynchronous microservices with Node.js and Express.js, while drawing on foundational languages like C++, C#, PHP, and Python for structured logic and algorithmic thinking. Data persistence is central to my work: I design normalized relational architectures using MySQL, Microsoft SQL Server, and SQLite to enforce ACID compliance and optimal indexing, alongside document-based models in MongoDB for flexible scaling.<br><br>Bridging software and infrastructure, I work across Unix-like environments via Windows Subsystem for Linux (WSL) and native setups to manage processes, system permissions, and deployment workflows. My operational experience extends to cPanel server configuration, Apache and Nginx reverse proxying, DNS management, and automated SSL/TLS deployments. To ensure code reliability, I design automated end-to-end testing suites using Katalon Studio. Furthermore, my curiosity in system vulnerabilities drives active participation in Capture The Flag (CTF) challenges on picoCTF, where exploring reverse engineering, cryptography, and binary exploitation reinforces a security-first engineering mindset.<br><br>Beyond independent development, I serve as an Academic Laboratory Teaching Assistant across three fundamental domains: Computer Hardware, Operating Systems, and Database Management Systems. Guiding students through hands-on diagnostics, concurrency issues, and SQL query optimization has strengthened my communication and pedagogical patience. Outside the university lab, I apply my skills to grassroots initiatives—most notably architecting and maintaining the official digital platform for Desa Wisata Banaran to support regional tourism. Concurrently, as Project Manager for an AI-integrated financial tracking application, I lead the integration of machine learning APIs with transactional ledger systems to deliver intelligent financial insights.<br><br>My engineering practice is complemented by institutional leadership. As Public Relations Division Lead for IT Specta, I directed stakeholder communication and large-scale team workflows. Serving as Project Leader for an inter-departmental comparative study with the Accounting Student Association further sharpened my skills in administrative governance and institutional diplomacy.<br><br>To maintain cognitive endurance across demanding academic and engineering schedules, I deliberately recharge through high-intensity competitive mobile gaming in Call of Duty Mobile, balanced by classic acoustic and pop music. I remain focused on building scalable digital platforms, mentoring future engineers, and directing impactful projects that create tangible value.
